# Releases

This file tracks prototype versions and public demo milestones.

## Versioning Scheme

The project uses semantic-style prototype versions:

- `v0.1.x` - schedule demo foundation;
- `v0.2.x` - AI prototype and responsive demo improvements;
- `v0.3.x` - public GitHub demo prepared through issues and pull requests.

## Previous Prototype Milestones

These milestones describe the prototype work before the clean public GitHub history was started.

### v0.1.0 - Schedule Demo Foundation

- Extracted schedule data from the original single-file demo.
- Introduced the first frontend-only schedule experience.
- Prepared schedule filters and display logic.

### v0.2.0 - AI Prototype Demo

- Added the AI assistant tab.
- Added deterministic demo scenarios for study-related questions.
- Added visual response scenes connected to chat answers.

### v0.2.1 - Responsive AI Details

- Added a visible details link/hint to AI answers.
- Improved mobile behavior for opening visual details from the chat.
- Documented the prototype as desktop-first with responsive preview support.

### v0.2.2 - Polish Details Fix

- Fixed the AI answer details label for the Polish UI.
- Removed the remaining Russian details label from the public-facing source.
- Kept the AI response link consistent with the selected language.

## Release Checklist

Before tagging a public release:

- GitHub Pages link opens successfully.
- README explains current working scope and AI prototype limitation.
- Polish overview is suitable for WWSI review.
- Schedule module works without backend services.
- Day/night theme switching is visible in the UI.
- AI prototype behavior is clearly labeled as demo/simulation.
- Release notes mention the final public demo version.
